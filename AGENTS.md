# Instructions permanentes pour les agents IA

## Projet

Ce dépôt contient le site **L’Écho des Cendres : Le Livre-Monde**, une encyclopédie narrative interactive construite progressivement.

## Règles absolues

* Ne jamais inventer ou modifier le lore sans validation explicite du créateur.
* Ne jamais considérer une proposition d’IA comme canonique automatiquement.
* Proposer un plan avant toute modification importante.
* Ne modifier que les fichiers nécessaires à la tâche demandée.
* Ne jamais réécrire inutilement tout le projet.
* Expliquer les fichiers modifiés et les décisions prises.
* Préserver l’accessibilité, le responsive design et les performances.
* Ne jamais lancer `npm audit fix --force`.
* Ne jamais ajouter une dépendance sans expliquer son rôle et demander validation.
* Toujours vérifier le projet après modification.
* Toujours signaler les erreurs ou incertitudes.
* Le créateur valide la direction artistique, les animations et le contenu.

## Workflow

1. Lire `docs/PROJECT_STATE.md`, `docs/DECISIONS.md` et `docs/NEXT_STEPS.md`.
2. Examiner les fichiers concernés.
3. Proposer un plan limité.
4. Attendre validation avant une modification importante.
5. Modifier uniquement le périmètre demandé.
6. Lancer les vérifications appropriées.
7. Résumer les changements.
